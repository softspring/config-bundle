# Security Policy

## Supported Versions

This new package is only available on the experimental `6.1` development line.
There are no stable releases or supported `5.5` or `6.0` versions of this package.

## Reporting a Vulnerability

Please report security issues privately to `security@softspring.es`.
Do not open public GitHub issues for security vulnerabilities.

Include the affected version, steps to reproduce, impact, and any suggested fix.
